📚 ISI SETIAP FOLDER

Setiap direktori pertemuan dapat berisi beberapa file yang berkaitan dengan kegiatan praktikum, seperti:

- "README.md" → penjelasan dan laporan praktikum
- Source code → program yang dibuat selama praktikum
- Dokumentasi → screenshot atau bukti hasil percobaan
- File konfigurasi → konfigurasi yang diperlukan
- Hasil eksperimen → output dari program atau percobaan

Struktur tersebut dibuat supaya hasil praktikum dapat ditemukan dengan mudah berdasarkan nomor pertemuannya.
